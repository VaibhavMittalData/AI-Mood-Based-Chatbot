I developed an interactive AI chatbot focused on dynamic personality-based conversations, aligned with my interest in Generative AI and Conversational Systems. The chatbot is designed to simulate different emotional tones such as Angry, Funny, and Sad, allowing users to experience varied conversational behaviors within a single application.

The core of the project leverages Large Language Models (LLMs), specifically Groq’s LLaMA-3.3-70B model, integrated using the LangChain framework. This integration enables efficient prompt handling, structured message flow, and real-time response generation.

A key feature of the system is session-based memory, which allows the chatbot to retain conversational context during interactions. This enhances user experience by making conversations more coherent and personalized rather than stateless.

The application is built using Streamlit, providing a simple and interactive web interface for users to select personalities and engage in conversations seamlessly.

From a technical perspective, this project helped me gain hands-on experience in:

Prompt engineering and personality conditioning

LLM integration and API handling

Context management using memory modules

Building and deploying interactive AI applications

This project aligns strongly with my preferred domain of AI/ML, especially Generative AI, and reflects my interest in building intelligent, user-centric systems.
